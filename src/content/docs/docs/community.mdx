`llms.txt` 是一项面向全体 Web 作者、文档平台与智能体开发者的开放标准提案，欢迎社区持续贡献真实反馈与改进建议。

## 官方渠道与代码仓库

- **GitHub 主仓库**：[AnswerDotAI/llms-txt](https://github.com/AnswerDotAI/llms-txt)
- **英文原版非正式规范文档**：[`nbs/index.qmd`](https://github.com/AnswerDotAI/llms-txt/blob/main/nbs/index.qmd)（支持版本控制与公开 Issue / PR 讨论）
- **社区 Discord 频道**：[加入官方 Discord](https://discord.gg/aJPygMvPEN)，与各地作者交流实操经验并讨论最佳实践。

## 你可以如何参与

1. **为你的站点上线 `/llms.txt`**：哪怕先从几条核心文档链接与摘要开始，并用真实编程智能体测试效果。
2. **补充 `Link:` 发现响应头**：在静态宿主或 CDN 上为文档目录配置 `rel="alternate" type="text/markdown"` 与 `rel="describedby"`。
3. **提交到公共目录或分享案例**：将已上线的站点提交至 [llmstxt.site](https://llmstxt.site/) 或 [llmstxthub.com](https://llmstxthub.com/)，帮助更多团队参考借鉴。
